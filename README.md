# MultiQuant

Multi-Asset Quant Research Platform

## Features

- Data Ingestion (Yahoo Finance)
- Technical Indicators
  - RSI
  - MACD
  - ADX
  - ATR
  - EMA
  - Bollinger Bands
- Macro Features
  - DXY
  - VIX
  - US10Y
- Future Return Prediction

## Structure

config/
features/
ingest/
data/

## Run

python main.py

python build_features.py

python build_macro.py
